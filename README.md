# 콜미토닥이

서울·인천·경기와 천안·아산·청주·대전을 대상으로 하는 여성전용 출장마사지 안내 사이트입니다. `/Users/ssm/Documents/Services/Templetes/Template1`의 와인·골드 레이아웃을 바탕으로 새 콘텐츠와 새 이미지만 사용합니다.

## 현재 범위

- 홈 1개, 고정 안내 4개, 블로그 허브 1개·게시물 2개, 지역 104개
- 지역 범위: 7개 상위 권역 + 97개 행정시·행정구
- 동·읍·면·군 페이지 없음
- 지역별 핵심 검색어: 토닥이, 여성전용마사지, 여성전용출장마사지
- 지역 이미지 18장, 원본당 최대 6개 경로 배정
- 별도 홈 이미지 1장
- sitemap 112개 URL
- 공개 전 `noindex` 및 robots 전체 차단 유지

## 명령

```bash
npm install
npm run dev
npm test
npm run lint
npm run build
```

이미지 원본 검수와 배정은 프로젝트 밖의 공용 파이프라인에서 끝낸 뒤 아래 명령으로만 활성화합니다.

```bash
npm run images:release:callme
```

이 명령은 루트 검수 영수증, 원본 SHA-256, 1672×941 규격, 19개 원본의 유일성, 104개 경로의 `14×6 + 4×5` 재사용 제한을 모두 확인한 뒤 57개 반응형 WebP와 런타임 매니페스트를 생성합니다. 기존 출력은 덮어쓰지 않습니다.

## 배포 전 확인

- 실제 도메인으로 canonical, OG URL, sitemap host를 교체
- 배포 확인 후에만 `noindex`와 robots 전체 차단 해제
- 네이버 서치어드바이저 등록은 도메인·배포가 확정된 뒤 진행
