# 콜미토닥이 오너 브리프

## 브랜드와 템플릿

- 공개 브랜드: `콜미토닥이`
- 프로젝트 ID: `callme-todaki`
- 디자인 정본: `/Users/ssm/Documents/Services/Templetes/Template1`
- 기존 `스타토닥이` 디자인·폰트·이미지·생성 콘텐츠는 폐기 대상으로 보고
  새 런타임에서 사용하지 않는다.

## 지역 범위

- 서울, 인천, 경기, 천안, 아산, 청주, 대전
- 행정시·행정구까지만 생성
- 동·읍·면·군 페이지 제외
- 잠긴 목표: 7개 서비스 root + 97개 시/구 = 104개 지역 페이지
- 제외 군: 강화군, 옹진군, 가평군, 양평군, 연천군

## 검색어와 콘텐츠

- 핵심 3개: `{지역}토닥이`, `{지역}여성전용마사지`,
  `{지역}여성전용출장마사지`
- 보조 검색어는 MassageBom 메타 패밀리 중 실제 서비스에 맞는 소수만 사용
- 예시 방향: `수원토닥이`, `수원 여성전용출장마사지`를 중심으로 지역 후킹과
  소개를 구성
- 같은 지역 MassageBom 페이지의 운영 사실·섹션 흐름을 기준으로 하되,
  콜미토닥이 문체로 자연스럽게 가볍게 재작성
- 가격·결제·상담·Q&A 같은 검증된 운영 정보는 정본을 그대로 사용할 수 있음

## 토닥이 전용 코스와 섹션 순서

- 코스는 `센슈얼 감성 테라피` 한 가지다.
- 60분 120,000원 / 90분 150,000원 / 120분 180,000원.
- 기존 타이·아로마·힐링·스페셜 코스는 토닥이 플랫폼에서 사용하지 않는다.
- 단일 코스 가격표는 홈, 가격안내, 모든 지역 페이지에서 넓고 크게 표시한다.
- 가격표는 기존 정보 흐름의 위치를 유지하고, 지역 카드 목록만 각 페이지 본문의 마지막 섹션으로 둔다.
- 이 규칙은 이후 제작하는 모든 토닥이 계열 플랫폼의 기본값이다.

## 이미지

- 성인 한국인 여성 관리사 중심의 콜미토닥이 전용 신규 이미지
- Massage Love와 구도·공간·색조를 겹치지 않게 설계
- 지역 배너는 원본당 최대 6개 경로
- 104개 지역 기준 최소 18장: 14장×6 + 4장×5
- 홈 이미지는 지역 배정과 분리한 별도 1장
- route header는 각 배너 상단 팔레트보다 조금 더 짙은 반투명 그라데이션

## 빠른 완료 기준

1. Template1 기반 홈을 먼저 로컬 미리보기로 오너에게 보여준다.
2. 승인된 틀로 104개 지역과 고정 페이지를 확장한다.
3. title/description/H1과 핵심 본문 exact 중복을 코드로 확인한다.
4. build 1회와 대표 경로 렌더만 확인한다.
5. 비이미지 완료 뒤 이미지 19장(홈 1 + 지역 18)을 생성·검수·배정한다.
